---
description: Диагностика установки bear-skills — почему скилл не срабатывает
---

Продиагностируй установку bear-skills.

Запусти проверку и разбери вывод:

```bash
bear-skills doctor
```

Она проходит по пяти направлениям: требования доменов, битые симлинки, каналы установки, коллизии имён, пересекающиеся триггеры.

Если проверка чистая, а скилл всё равно не срабатывает — посмотри статистику:

```bash
bear-skills stats
```

Скилл с нулём вызовов при том, что задача возникала, означает проблему в `description`: модель не находит скилл по описанию.

Объясни найденное человеческим языком и предложи конкретное действие. Ничего не чини без подтверждения. Переустановку не предлагай первым шагом — она прячет причину, и та возвращается.

# Домен `agentops`

Гигиена работы с агентом: как тратить контекст и токены. В отличие от остальных доменов, здесь нет предметной области — эти скиллы про сам процесс работы с моделью.

| Поле | Значение |
|------|----------|
| `requires_env` | — |
| `requires_bin` | — |
| `rules` target | `~/.claude/rules/` |
| `skills` target | `~/.claude/skills/` |
| `agents` target | `~/.claude/agents/` |

Манифест: [`domains/agentops/manifest.yaml`](../../../domains/agentops/manifest.yaml).

## Состав

### Правила

| Правило | Что внутри |
|---------|-----------|
| `agentops-auto-clarity` | Где сокращение выключается: security, необратимое, многошаговое, повторный вопрос. Общее для всех сокращающих скиллов |

### Скиллы

| Скилл | Что делает | Когда вызывать |
|-------|------------|----------------|
| `agentops-compress` | Сжимает memory-файлы (`CLAUDE.md`, `AGENTS.md`, правила) со скриптовой проверкой сохранности | «сожми CLAUDE.md», «правила занимают много контекста» |
| `agentops-canary` | Канарейка контекста + протокол выхода при деградации | «поставь канарейку», «длинная сессия» |
| `agentops-delegate` | Что делегировать сабагенту, а что делать самому; контракты вывода | «стоит ли звать сабагента», «контекст кончается» |
| `agentops-brevity` | Режим сжатых ответов, три уровня, Auto-Clarity | «покороче», «без воды» |

### Агенты

- **`bear-locator`** (haiku, read-only) — находит позиции в коде, формат `path:line — symbol — note`, отказ `No match.`
- **`bear-surgeon`** — правка максимум в двух файлах, терминальные токены отказа `too-big.` / `needs-confirm.` / `ambiguous.` / `regressed.`
- **`bear-reviewer`** (haiku) — находки одной строкой с уровнем 🔴 bug / 🟡 risk / 🔵 nit / ❓ q

## Принципы

- **Memory-файл стоит токенов в каждой сессии.** Поэтому `agentops-compress` даёт эффект, которого не даёт разовая экономия на выводе.
- **Вывод сабагента вклеивается дословно.** Делегирование экономит бюджет главного окна только если сабагент читает много, а отвечает мало.
- **Контракт вывода фиксирован и грепается.** Иначе сабагент вернёт прозу, и ты заплатил за отдельный вызов впустую.
- **Ошибки краткости несимметричны.** Лишние токены стоят копейки, непонятое предупреждение — рабочего дня. При сомнении сокращение выключается.
- **Числа — оценки, пока не измерены.** Скрипт сжатия считает приближение по длине текста и обязан называть это оценкой.

Подробнее — в правиле `agentops-auto-clarity`.

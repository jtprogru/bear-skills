# Домен `bear`

Мета-домен: скиллы про саму коллекцию. Нужен ровно потому, что коллекция выросла — при тридцати с лишним скиллах в восьми доменах ни человек, ни модель не помнят состав наизусть.

| Поле | Значение |
|------|----------|
| `requires_env` | — |
| `requires_bin` | — |
| `rules` target | `~/.claude/rules/` |
| `skills` target | `~/.claude/skills/` |
| `agents` target | `~/.claude/agents/` |

Манифест: [`domains/bear/manifest.yaml`](../../../domains/bear/manifest.yaml).

## Состав

| Скилл | Что делает | Когда вызывать |
|-------|------------|----------------|
| `bear-help` | Справка по коллекции: домены, скиллы, установка | «что у меня есть», «есть ли скилл для X» |
| `bear-doctor` | Диагностика: битые симлинки, два канала разом, коллизии, пересекающиеся триггеры | «скилл не срабатывает», «вызывается не тот» |
| `bear-new-skill` | Создание скилла по шаблону коллекции со всем сопутствующим | «сделай скилл для X» |
| `bear-stats` | Что реально срабатывает, а что мертво — по логам сессий | «какие скиллы мёртвые», «что удалить» |

Все четыре опираются на команды CLI, а не на память модели: `bear-skills list`, `doctor`, `stats`.

## Команды, на которых они держатся

```bash
bear-skills list            # состав коллекции
bear-skills status          # что развёрнуто
bear-skills doctor          # пять проверок установки
bear-skills stats           # частота вызовов по логам сессий
bear-skills stats --since 30
```

`doctor` возвращает 1 при найденной проблеме и 0, если только предупреждения — годится для скрипта.

## Установка только этого домена

```bash
npx github:jtprogru/bear-skills install bear
```

## Принципы

- **Не помнить, а спрашивать.** Состав коллекции меняется; память модели о нём устаревает молча, поэтому мета-скиллы всегда идут в CLI.
- **Скиллы конкурируют за срабатывание.** Чем их больше, тем ниже точность выбора. Отсюда ценность `bear-stats`: мёртвый скилл ухудшает работу живых.
- **Триггеры живут в `description`.** Детектор пересечений смотрит только туда — кавычки из тела скилла дают шум, в котором тонет сигнал.
- **Причина важнее переустановки.** `doctor` показывает, что именно сломано; переустановка прячет причину, и она возвращается.

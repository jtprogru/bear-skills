# Домен `content`

Контент-pipeline — Telegram-посты, статьи (Habr / Medium / личный блог), технические туториалы. Соблюдает авторский голос: «ты»/безличное, конкретика > обобщений, ноль маркетинговых штампов.

| Поле | Значение |
|------|----------|
| `requires_env` | — |
| `rules` target | `~/.claude/rules/` |
| `skills` target | `~/.claude/skills/` |
| `agents` target | `~/.claude/agents/` |

Манифест: [`domains/content/manifest.yaml`](../../../domains/content/manifest.yaml).

## Состав

### Правила

| Правило | Что внутри |
|---------|-----------|
| `content-voice` | Авторский голос, тон, запреты (никаких «дорогих читателей», ИИ-штампов, маркетинга) |
| `content-formatting` | Форматирование под платформы: Telegram, Markdown-статьи, туториалы |

### Скиллы

| Скилл | Что делает | Когда вызывать |
|-------|------------|----------------|
| `content-tg-post` | Превращает идею в пост 500-1500 символов с тезисом первым | «написать пост в тг», «оформить мысль для канала» |
| `content-article-draft` | Драфт статьи 3-10к символов: тезис → аргументы → пример → следствие | «написать статью», «черновик для Habr» |
| `content-tutorial-structure` | Скелет технического туториала: цель, шаги, проверки, troubleshooting, cleanup | «написать туториал», «how-to», «инструкция как сделать X» |
| `content-humanizer` | Очеловечивает русскоязычный AI-текст: убирает маркеры нейросети, возвращает авторский голос и ритм | «очеловечить текст», «убрать следы нейросети», «звучит как робот» |
| `content-zavod` | Из одного источника (статья, транскрипция, тема) делает пакет: статья, 10 тредов, 5 Reels, 5 постов, 3 карусели, контент-план — 6 файлов | «контент-завод», «размножь видео на контент», «нарежь сценарий на посты и рилсы» |

`content-zavod` — самый крупный скилл домена и единственный, который пишет несколько файлов за проход. Матрица углов внутри защищает единицы контента от самоповторов, каждый текст проходит антиИИ-фильтр.

### Агенты

- **`content-editor`** — внутренний редактор: помогает выбрать формат, вызывает нужный скилл, ведёт до публикации.

## Установка только этого домена

```bash
npx github:jtprogru/bear-skills install content
```

## Принципы

- **Тезис первым.** Если убрать первые 1-3 предложения, теряется ли смысл? Если нет — выкидывай вступление.
- **Конкретика > обобщения.** Числа, примеры, код. Не «как показывает практика».
- **Никаких ИИ-штампов.** «Давайте погрузимся», «в этой статье мы рассмотрим», «таким образом» — режь.
- **Авторский голос важнее формальной правильности.** Личные оценки и сомнения автора — оставляй.
- **Не публикуй за автора.** Даже если есть техническая возможность.

Подробнее — в правилах `content-voice` и `content-formatting`.

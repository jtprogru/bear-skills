# Правило: `file-naming`

Именование файлов заметок: claim-based стиль и запрещённые символы.

## Что внутри

- **Запрещённые символы:** `: / \ * ? " < > |` — ломают файловые системы и wikilinks
- **Стиль:** claim-based (выражает утверждение), а не topic-based (название темы)
  - Плохо: `Exponential backoff`
  - Хорошо: `Exponential backoff защищает от каскадных сбоев`
- **Признаки хорошего имени:** конкретное, самодостаточное, краткое (4–8 слов), на языке хранилища
- **Паттерны имён:** серии заметок через тире `–`, лекции, литературные заметки
- **Проверка перед созданием:** нет дубликата, нет запрещённых символов, имя самодостаточно

## Кто применяет

Любой скилл, создающий новые заметки или переименовывающий существующие:

- `obsidian-ingest` — имена атомарных заметок
- `obsidian-split-note` — имена выделяемых атомарок
- `obsidian-refactor-lecture` — имена концептов
- `book-highlights-processor` — заголовки callout-ов (будущие имена файлов)

## Точечная установка

```bash
bear-skills install rule:file-naming
```

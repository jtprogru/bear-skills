# Правило: `knowledge-structures`

MOC, синтезы, атомарные заметки — структурные образования над сырыми заметками.

## Что внутри

- **MOC (Map of Content):**
  - Что это, когда создавать (тема в 5+ заметках без точки входа)
  - Структура MOC: `## Описание`, `## Ключевые заметки`, `## Связанные темы`, `## Автосбор` (dataview)
  - Правила: краткая аннотация к каждой ссылке, dataview-запрос для автоматического сбора
- **Синтез-заметки:**
  - Сравнение нескольких концептов/инструментов
  - Структура: `## Сравнение`, `## Анализ`, `## Рекомендация`, `## Связанные заметки`
  - В `sources` — все исходные заметки
- **Атомарные заметки:**
  - Когда выделять: самостоятельная мысль, идея повторяется в нескольких заметках, тема разрослась
  - Как выделять: определи идею → создай заметку → frontmatter → суть своими словами → ссылки → в исходной заметке замени блок на wikilink
- **Когда выделять раздел в отдельную заметку** — критерии «выделяй» vs «оставь в оригинале»

## Кто применяет

- `obsidian-split-note` — выделение атомарок из большой заметки
- `obsidian-refactor-lecture` — извлечение концептов из конспекта
- `obsidian-untangle-knot` — создание под-MOC при разгрузке hub
- `obsidian-ingest` — создание атомарок из источника
- Агент `knowledge-cartographer` — оркестрация всего вышеперечисленного + создание MOC и синтезов вручную

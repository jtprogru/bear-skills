# Правило: `mermaid`

Init-строка для mermaid-схем в Obsidian — чтобы они рендерились во всю ширину.

## Что внутри

- **Обязательная init-строка** для каждого mermaid-блока в заметке:
  ```
  %%{init: {"flowchart": {"useMaxWidth": true}}}%%
  ```
- Идёт **первой строкой** в блоке mermaid, до объявления типа диаграммы
- Применяется ко всем типам диаграмм (flowchart, sequenceDiagram и т.д.)
- При рефакторинге существующих mermaid-блоков без init-строки — добавлять её

## Зачем

По умолчанию mermaid в Obsidian рендерится по фиксированной ширине, и схема обрезается / занимает узкий столбец. `useMaxWidth: true` растягивает её по ширине заметки.

## Кто применяет

Любой скилл, генерирующий или редактирующий mermaid-блоки:

- `obsidian-ingest` — при визуализации концептов
- `obsidian-split-note`, `obsidian-refactor-lecture` — при сохранении/переносе схем
- Ручные правки заметок через Claude

## Точечная установка

```bash
bear-skills install rule:mermaid
```

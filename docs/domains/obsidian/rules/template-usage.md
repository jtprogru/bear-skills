# Правило: `template-usage`

Когда какой шаблон заметки применять — таблица решений и разграничение похожих шаблонов.

## Что внутри

- **Таблица «что хочу зафиксировать → какой шаблон»:** книга, видео, статья, доклад, лекция, мысль, идея, концепт, проект, MOC, профиль человека, встреча, инцидент и т.д.
- **Разграничение похожих шаблонов:**
  - Мысль vs Идея vs Концепт (разные `confidence`, разные `tags`, разное «что дальше»)
  - Тезисы по источнику vs Литературная заметка
  - Доклад vs Конференция
  - Карта vs Топик
- **Правила заполнения шаблонов:** обязательные поля `aliases`/`up`/`tags`, поле `confidence`, поле `sources`, поле `status`
- **Журнальные заметки:** когда создавать ежедневную/еженедельную/ежемесячную/ежегодную
- **Что не создавать через шаблон:** разделы внутри заметок, ссылки-заглушки, временные черновики в inbox

## Кто применяет

- `obsidian-ingest` — выбирает шаблон под тип источника
- `obsidian-daily-append` — может создать ежедневную по шаблону, если её ещё нет
- `obsidian-refactor-inbox` — выбирает шаблон при типизации входящей

## Точечная установка

```bash
bear-skills install rule:template-usage
```

## Зависимости

Опирается на [`note-types-frontmatter`](note-types-frontmatter.md) (что за поля в каждом шаблоне).

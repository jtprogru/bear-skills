# Правило: `vault-struct`

Структура папок Obsidian-хранилища по методологии PARA. Фундаментальное правило — без него непонятно, куда класть заметки и где их искать.

## Что внутри

- Обзор хранилища: тип, язык, корневой путь (параметризуется через `--vault` / `BEAR_VAULT`)
- ASCII-дерево структуры папок:
  - `_Система/` — шаблоны, статика, холсты, импорты
  - `00. Входящие/` — inbox
  - `01. Проекты/` — PARA Projects
  - `02. Сферы/` — PARA Areas (люди, работа, личное развитие, образование, медийность, конференции, здоровье, бренд)
  - `03. Ресурсы/` — PARA Resources (книги, статьи, литературные заметки, заметки, видео, промты, карты)
  - `04. Архив/` — PARA Archives; для агента это **плоская** директория, подпапки он там не создаёт
  - `05. Дневник/` — ежедневные заметки

## Кто применяет

Практически все скиллы и агенты — это самая базовая ссылка. Указывается первой в списке зависимостей.

## Точечная установка

```bash
bear-skills install rule:vault-struct
```

## Если структура хранилища отличается

Это правило отражает структуру **конкретного PARA-vault** автора. Если у тебя другая структура — форкни репо и поменяй `rules/vault-struct.md` под себя. Все скиллы автоматически начнут опираться на твою версию через симлинк.

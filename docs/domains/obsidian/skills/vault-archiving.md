# Skill: `vault-archiving`

Правила переноса заметок в `04. Архив/`.

## Назначение

Фиксирует два правила, которые нарушаются чаще всего:

1. **Заметки не удаляются.** Устаревшее переезжает в архив с тегом `#archive`, ссылки и связи остаются нетронутыми — они часть графа.
2. **Архив для агента плоский.** Подпапку под группу переносимых заметок не создают никогда — ни под тему, ни под источник, ни под дату, ни под «пачку из этой сессии».

Плюс порядок `mv`, разбор конфликта имён и список того, кто архивирует в рабочем цикле.

## Триггеры

- «в архив»
- «заархивируй заметку»
- «это устарело»
- массовая архивация темы или папки

## Границы

Массовая архивация — тяжёлый рефакторинг: только по явному запросу и через протокол «план → подтверждение → действие».

# Skill: `vault-stats`

Статистика хранилища и поиск мёртвых заметок.

## Назначение

Ведёт по цепочке скриптов `.agents/scripts/vault_stats_*.py`:

```bash
python3 .agents/scripts/vault_stats_graph.py    # связность, плотность, частота правок, композитный скор
python3 .agents/scripts/vault_stats_lexdup.py   # шаблонный каркас и текстовые дубли
```

Дальше — эмбеддинги, семантические дубли и изоляты, калибровка весов по истории git-удалений. Порядок запуска обязателен: каждый шаг читает выхлоп предыдущих. Отдельно описывает launchd-агенты, которые собирают журнальные выжимки weekly и monthly сами.

## Триггеры

- «какие заметки бесполезны»
- «статистика базы»
- «мёртвые заметки»
- «посчитай связность»
- «что там собирает weekly по расписанию»

## Границы

Скор ранжирует список на разбор, а не выносит приговор. В рабочем цикле скилл не участвует — только по явному запросу.

Заметок скрипты не трогают. Единственное исключение — `calibrate`, который перезаписывает `.agents/scripts/vault_stats_weights.json` и тем меняет поведение скоринга при следующих прогонах; флага «только посчитать» у него нет, откат — через git. Шаг `embed` требует поднятого LM Studio.

## Зависимости

**Правила:**

- [`vault-struct`](../rules/vault-struct.md) — что считать заметкой, а что служебным файлом

Промежуточные файлы кладутся в каталог из `VAULT_STATS_OUT` (по умолчанию временный).

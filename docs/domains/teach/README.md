# Домен `teach`

Обучение новой теме на русском языке. Один скилл, который превращает рабочую директорию в учебный воркспейс и ведёт тему через несколько сессий.

| Поле | Значение |
|------|----------|
| `requires_env` | — |
| `requires_bin` | — |
| `rules` target | `~/.claude/rules/` |
| `skills` target | `~/.claude/skills/` |
| `agents` target | `~/.claude/agents/` |

Манифест: [`domains/teach/manifest.yaml`](../../../domains/teach/manifest.yaml).

## Состав

| Скилл | Что делает | Когда вызывать |
|-------|------------|----------------|
| `teach-ru` | Миссия, проверенные источники, короткие HTML-уроки с квизами, записи усвоенного и глоссарий в текущей директории | `/teach-ru <тема>`, только явной командой: сам скилл не срабатывает |

Правил и агентов в домене нет.

## Как пользоваться

```bash
mkdir -p ~/learn/k8s-networking && cd ~/learn/k8s-networking
claude
# в сессии: /teach-ru сетевая модель Kubernetes
```

Первая сессия начнётся с вопросов о том, зачем тебе тема, и с поиска источников. Следующие запускай в той же директории: скилл читает записи усвоенного и сам выбирает урок, если не назвать конкретную тему.

## Установка только этого домена

```bash
npx github:jtprogru/bear-skills install teach
```

## Принципы

- **Цель — долговременное удержание.** Лёгкость «по горячим следам» создаёт иллюзию мастерства, поэтому уроки строятся на вспоминании по памяти и интервалах.
- **Источники важнее памяти модели.** Утверждения в уроке подкреплены ссылками.
- **Один урок — одна победа.** Рабочая память маленькая, урок должен в неё влезать.
- **Термины английские, объяснение русское.** Глоссарий выбирает одно написание и закрывает вопрос.

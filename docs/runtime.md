# Runtime: хук, statusline, команды

Необязательный слой. Скиллы работают без него — хук лишь избавляет от повторения общего контракта в каждой сессии.

## Что делает хук

`hooks/bear-activate.js` вешается на `SessionStart` и делает две вещи: печатает в stdout общий контракт работы (Claude Code подхватывает это как системный контекст) и пишет флаг для statusline.

Инжектится **только общий контракт**: протокол «план → подтверждение → действие → отчёт», язык и тон, чего не делать. Не все правила подряд — правила домена читает скилл, когда срабатывает, и дублировать их в каждой сессии значит платить за них всегда, включая сессии, где домен не нужен.

Если в `~/.claude/skills/` нет ни одного скилла коллекции, хук молчит. Инжектить контракт коллекции в чужой проект, где её нет, — трата токенов.

## Два свойства, на которых всё держится

**Хук молча падает.** Любая ошибка — выход с кодом 0 и пустым выводом. Сломанный `SessionStart` ломает каждую сессию, и эта цена несопоставима с ценой неинжектированного контракта. Поведение закреплено тестами: хук вызывается с заведомо невалидным `CLAUDE_CONFIG_DIR` и обязан выйти чисто.

**Запись symlink-safe.** Флаг лежит по угадываемому пути в домашнем каталоге. Подмени его симлинком на чужой файл — и обычная запись пойдёт по ссылке, перезаписав цель правами пользователя. Поэтому [`hooks/lib/safe-write.js`](../hooks/lib/safe-write.js) отказывается писать, если симлинком оказался сам файл **или его родительский каталог**, открывает с `O_NOFOLLOW`, заменяет файл атомарно через временный и ставит режим `0600`.

Проверка родителя не менее важна, чем проверка файла: подменённый каталог уводит запись целиком, сколько бы проверок ни стояло на самом имени.

## Statusline

`hooks/bear-statusline.sh` рисует бейдж вида `🐻 3` — число активных доменов.

Содержимое флага он считает **недоверенным**: это файл в домашнем каталоге, куда мог написать кто угодно. Имена доменов проходят через whitelist, и наружу печатается только то, что его прошло. Произвольные байты из файла в вывод не попадают никогда.

Подключение:

```json
{
  "statusLine": {
    "type": "command",
    "command": "~/.claude/hooks/bear-statusline.sh"
  }
}
```

## Слэш-команды

| Команда | Что делает |
|---|---|
| `/bear [домен]` | Справка по коллекции из фактического состояния, а не по памяти |
| `/bear-doctor` | Диагностика: почему скилл не срабатывает |
| `/bear-stats [дней]` | Что реально вызывается, а что мертво |

Все три идут в CLI за данными вместо того, чтобы пересказывать содержимое коллекции по памяти: состав меняется, а память о нём устаревает молча.

## Установка

Через плагин Claude Code хуки и команды приезжают вместе с ним — конфигурация в [`hooks/hooks.json`](../hooks/hooks.json).

Вручную, при симлинк-установке:

```bash
mkdir -p ~/.claude/hooks
ln -sf "$PWD/hooks/bear-activate.js"   ~/.claude/hooks/
ln -sf "$PWD/hooks/bear-statusline.sh" ~/.claude/hooks/
```

И зарегистрировать `SessionStart` в `~/.claude/settings.json` по образцу `hooks/hooks.json`.

Проверить, что хук ведёт себя тихо, можно до установки:

```bash
CLAUDE_CONFIG_DIR=/tmp/пусто node hooks/bear-activate.js   # молчит
node --test tests/hooks.test.js                            # включая symlink-атаку
```

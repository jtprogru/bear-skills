# agentops-brevity

Режим сжатых ответов на остаток сессии: три уровня плотности с автоматическим отключением там, где краткость опасна.

## Когда срабатывает

«Покороче», «без воды», «отвечай сжато», «не расписывай». И обратно: «нормальный режим», «можно подробнее».

## Уровни

`lite` — убрана вода, структура прежняя. `full` — плотно, одна мысль на предложение, объяснение только при необходимости. `ultra` — прямой ответ плюс максимум строка обоснования.

## Auto-Clarity

Самая важная часть. Режим выключается сам — молча, без вопросов — на предупреждениях о безопасности, необратимых действиях, многошаговых инструкциях для человека, повторном вопросе пользователя и разборе чужой ошибки.

Логика в асимметрии ошибок: лишние токены стоят копейки, непонятая инструкция про `push --force` стоит рабочего дня. При сомнении режим отключается.

Полный список условий — в правиле [`agentops-auto-clarity`](../../rules/agentops-auto-clarity.md), общем для всех сокращающих скиллов.

## Не путать со слоями

Этот скилл сокращает вывод **модели**. Вывод команд сокращает `rtk`. Слои разные, друг друга не заменяют и не конфликтуют.

И отдельно: режим касается речи агента, а не продукта работы. Если попросили статью — статья пишется нормальной длины, даже в `ultra`.

## Границы

Не сокращает код, команды, пути и сообщения об ошибках — они воспроизводятся дословно. Не меняет язык ответа. Не выдумывает сокращения слов: токенайзер не считает `конф` дешевле `конфигурации`, а читать хуже.

# bear-help

Справочная карточка по коллекции: какие есть домены и скиллы, что делает каждый, как поставить и снять.

## Когда срабатывает

«Что у меня вообще есть», «какие скиллы установлены», «есть ли скилл для X», «как отключить скилл».

## Зачем нужен

При тридцати с лишним скиллах в восьми доменах вспомнить состав по памяти невозможно — ни человеку, ни модели. А память модели о составе устаревает молча: скиллы добавляются, а она продолжает рассказывать про старый набор.

Поэтому скилл не пересказывает по памяти, а спрашивает у CLI (`bear-skills list`, `bear-skills status`) и отвечает по факту.

## Границы

Состояние не меняет: ничего не ставит, не снимает и не правит. На вопрос «есть ли скилл для X» отвечает честно, если подходящего нет, вместо того чтобы выдать отдалённо похожий.

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`bear`](../../../../docs/domains/bear/README.md).

# content-humanizer

Убирает из русскоязычного текста следы AI-генерации и возвращает живой авторский ритм.

## Когда срабатывает

«Очеловечить текст», «убрать следы нейросети», «звучит как робот», «убрать канцелярит», «слишком искусственно». Также когда пользователь вставляет русский текст со словами «перепиши» или «сделай лучше».

## Что делает

Работает от каталога тэллов — конкретных признаков машинного текста, а не от общего ощущения. Классифицирует текст по регистру (статья, пост, письмо, документация) и правит под него: то, что уместно в блоге, неуместно в доке. Цикл идёт сканированием и повторной проверкой, потому что переписывающая модель заносит те же признаки обратно в парафразе.

Полный каталог русских тэллов с регексами — в [`references/tells-ru.md`](references/tells-ru.md).

## Скрипты

Три скрипта без зависимостей, Python 3.9+. `pymorphy3` подхватывается, если установлен, и добавляет одну метрику.

```bash
python3 scripts/scan_tells.py текст.md --sections   # штампы, плотность, разбивка по секциям
python3 scripts/scan_rhythm.py текст.md             # ритм: дисперсия длин, ровные участки
python3 scripts/scan_tells.py до.md после.md        # что добавилось при переписывании
python3 scripts/calibrate.py ~/blog/posts --write   # пересобрать пороги под свой архив
```

Пороги живут в `scripts/baseline.json` и собираются по корпусу автора, а не берутся из головы. Свой архив — своя норма.

## Границы

Только русский язык. Не переводит, не пишет с нуля, не правит грамматику как самоцель и не трогает код. Авторские шероховатости — не ошибки: сглаживать их означает вернуть текст туда, откуда его вытаскивают.

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`content`](../../../../docs/domains/content/README.md).

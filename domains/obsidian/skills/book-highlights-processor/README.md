# book-highlights-processor

Превращает экспорт цитат из iBooks или Zotero в читаемые Obsidian-callouts с заголовками и выделенными ключевыми фразами.

## Когда срабатывает

«Обработай цитаты», «добавь заголовки к хайлайтам», «разбери экспорт из книги», «обработай импорт из iBooks».

## Что делает

Сырой экспорт — это список цитат без структуры, по которому невозможно вспомнить, зачем ты это выделил. Скилл даёт каждой цитате заголовок в стиле атомарной заметки и подсвечивает `==ключевую фразу==` внутри, чтобы при перечитывании глаз цеплялся за суть.

## Границы

Не переписывает цитаты — текст автора остаётся дословным. Заголовок и выделение добавляются вокруг него.

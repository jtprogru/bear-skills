# knowledge-structures

Справочник по структурам знаний хранилища: MOC, синтез-заметки и атомарки.

## Когда срабатывает

Создание карты по теме, сравнение нескольких концептов, дробление конспекта или статьи на атомарные заметки.

## Что делает

Отвечает на три вопроса, которые иначе решаются на глаз: когда тема созрела до MOC (`#MapOfContent`), когда сравнение тянет на синтез (`#synthesis`), а когда вывод остаётся одной мыслью. Плюс критерии «выделять / оставить в оригинале» для разделов большой заметки.

## Границы

Само ничего не создаёт — это правило, на которое опираются `obsidian-ingest`, `obsidian-split-note` и `obsidian-untangle-knot`. Раньше жило как `rules/knowledge-structures.md`; стало навыком, чтобы не занимать контекст в каждой сессии.

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`obsidian`](../../../../docs/domains/obsidian/).

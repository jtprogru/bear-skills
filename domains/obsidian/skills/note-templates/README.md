# note-templates

Выбор шаблона Templater под ситуацию и рецепт его технического применения.

## Когда срабатывает

Создаётся новая заметка и надо решить, по какому шаблону из `_Система/1. Шаблоны/` её заводить.

## Что делает

Держит таблицу «ситуация → шаблон» и разбирает пары, которые путают чаще всего: мысль против идеи против концепта, тезисы по источнику против литературной заметки, карта против топика. Отдельно — вызов `obsidian templater:create-from-template` и его грабли: молчаливый дубль вместо перезаписи, невидимая свежесозданная папка, интерактивные шаблоны, которые через CLI не работают.

## Границы

Frontmatter по памяти не собирается: источник правды — файл шаблона в хранилище. Требует `BEAR_VAULT`. Раньше жило как `rules/template-usage.md`.

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`obsidian`](../../../../docs/domains/obsidian/).

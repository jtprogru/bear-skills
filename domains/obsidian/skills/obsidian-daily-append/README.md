# obsidian-daily-append

Добавляет запись в сегодняшнюю ежедневную заметку: мысль, событие, встречу, TODO, ссылку на атомарку.

## Когда срабатывает

«Добавь в сегодняшнюю заметку», «запиши в дневник», «зафиксируй в today», «отметь в дневнике».

## Что делает

Сам определяет тип записи и кладёт её в правильный раздел: мысли вслух, заметка дня, узел разбора, callout с TODO. Задаёт один-два уточняющих вопроса — про связи, проект, нужна ли отдельная атомарка — чтобы запись не осталась висеть без контекста.

Если заметки на сегодня ещё нет, создаёт её по шаблону.

## Границы

Не создаёт атомарные заметки — для этого [`obsidian-ingest`](../obsidian-ingest/README.md). Не делает ревью прошедших дней — для этого [`obsidian-journal-review`](../obsidian-journal-review/README.md).

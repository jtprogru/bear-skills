# obsidian-split-note

Разбивает большую заметку на атомарные, оставляя оригинал обзорной точкой входа со ссылками.

## Когда срабатывает

«Разбей заметку», «раздели на атомарные», «эта заметка слишком большая».

## Что делает

Находит в тексте самостоятельные концепты, выносит каждый в отдельную заметку с корректным frontmatter, а на их месте в оригинале оставляет wikilinks. Оригинал не пропадает — он становится оглавлением с `down` на всех детей.

## Границы

Не разбивает то, что не делится: если заметка про одну мысль, она останется одной заметкой. Соблюдает структуру PARA при выборе папок для новых заметок.

Требует `BEAR_VAULT`. Подробная документация — [`docs/domains/obsidian/skills/obsidian-split-note.md`](../../../../docs/domains/obsidian/skills/obsidian-split-note.md).

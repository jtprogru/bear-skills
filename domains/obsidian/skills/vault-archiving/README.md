# vault-archiving

Правила переноса заметок в `04. Архив/`.

## Когда срабатывает

Заметка утратила актуальность, обрабатывается инбокс, или запрошена массовая архивация темы или папки.

## Что делает

Фиксирует два правила, которые нарушаются чаще всего. Первое: заметки не удаляются — устаревшее переезжает в архив с тегом `#archive`, ссылки и связи остаются нетронутыми. Второе: архив для агента плоский, подпапку под группу переносимых заметок не создают никогда. Плюс порядок `mv`, разбор конфликта имён и список того, кто архивирует в рабочем цикле.

## Границы

Массовая архивация — тяжёлый рефакторинг: только по явному запросу и через протокол «план → подтверждение → действие». Требует `BEAR_VAULT`.

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`obsidian`](../../../../docs/domains/obsidian/).

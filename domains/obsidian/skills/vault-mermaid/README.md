# vault-mermaid

Обязательная init-строка в mermaid-блоках заметок.

## Когда срабатывает

Создаётся или правится mermaid-схема в заметке хранилища.

## Что делает

Каждая схема начинается со строки настройки `useMaxWidth` — без неё Obsidian рендерит диаграмму фиксированной ширины и обрезает её по краю заметки. Правило описывает точный синтаксис, место строки внутри блока и распространяется на все типы диаграмм, а не только на flowchart.

## Границы

Само схем не рисует. При правке существующих блоков без init-строки она дописывается. Раньше жило как `rules/mermaid.md`.

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`obsidian`](../../../../docs/domains/obsidian/).

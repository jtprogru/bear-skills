# vault-stats

Статистика хранилища и поиск мёртвых заметок.

## Когда срабатывает

«Какие заметки бесполезны», «статистика базы», «мёртвые заметки», «посчитай связность», а также вопросы про фоновую сборку weekly и monthly.

## Что делает

Ведёт по цепочке скриптов `vault_stats_*.py`: связность и композитный скор, текстовые дубли, эмбеддинги, семантические дубли и изоляты, калибровка весов по истории git-удалений. Порядок запуска обязателен — каждый шаг читает выхлоп предыдущих. Отдельно описывает launchd-агенты, которые собирают журнальные выжимки сами.

## Границы

Скор ранжирует список на разбор, а не выносит приговор. Заметок скрипты не трогают; единственное исключение — `calibrate`, переписывающий файл весов. `embed` требует поднятого LM Studio. Требует `BEAR_VAULT`.

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`obsidian`](../../../../docs/domains/obsidian/).

# Настройка: плагины, захват, клавиши

Нужна, когда система собирается заново, что-то сломалось в захвате или непонятно, почему плагин ведёт себя именно так. В обычной работе со строками задач хватает `SKILL.md`.

## Плагины

| Плагин | Зачем |
|--------|-------|
| Tasks | Задачи, дашборд, модалка `Cmd+Shift+T` |
| Dataview | Единственный срез, который Tasks собрать не может: «Чекбоксы без метки» |
| Periodic Notes | Ежедневная и недельная заметки, хоткеи |
| Daily Notes (встроенный) | Должен оставаться включённым, см. «Захват» |
| Advanced URI | Запись в `## Инбокс` снаружи Obsidian |
| Templater | Шаблоны дневника и проекта с tasks-блоками |

## Настройки Tasks

Источник правды — `.obsidian/plugins/obsidian-tasks-plugin/data.json`. Перед выводами о поведении плагина сверяйся с файлом, а не с этой таблицей.

| Ключ | Значение | Что даёт |
|------|----------|----------|
| `globalFilter` | `"#task"` | Задача — только строка с меткой, чеклисты не попадают в запросы |
| `removeGlobalFilter` | `false` | Метка остаётся видимой в отрисованной строке |
| `taskFormat` | `tasksPluginEmoji` | Сигнификаторы эмодзи: `⏫ 🔼 ➕ 🛫 ⏳ 📅 ❌ ✅ 🔁` |
| `setCreatedDate` | `true` | `➕` — только в модалке |
| `setDoneDate` | `true` | `✅` при закрытии |
| `setCancelledDate` | `true` | `❌` — только в модалке |
| `useFilenameAsScheduledDate` | `true` | `⏳` из имени файла, если дата не указана |
| `filenameAsDateFolders` | `["05. Дневник"]` | Автоподстановка только в дневнике |

Кастомные статусы:

| Символ | Имя | Тип | Следующий по клику |
|--------|-----|-----|--------------------|
| `/` | In Progress | `IN_PROGRESS` | `x` |
| `-` | Cancelled | `CANCELLED` | пробел |
| `?` | Waiting | `TODO` | `x` |

Тип `TODO` у ожидания означает, что `- [?]` считается незакрытой во всех запросах с `not done`.

### Поведение глобального фильтра

Модалка `Cmd+Shift+T` при открытии вырезает голую метку из описания по границе слова, а при сохранении возвращает её через `prependTo()` — в самое начало строки. Сам фильтр проверяется подстрокой (`includedIn()`), поэтому `#task/deep` его проходит, но модалкой не вырезается и остаётся на месте. Отсюда в `SKILL.md` правило «метку в начале не переставлять» и практика «тип работы вместо голой метки».

## Захват

Три двери, все пишут в `## Инбокс` сегодняшнего дневника:

| Дверь | Как | Когда |
|-------|-----|-------|
| Дневник | `Cmd+D` → секция `## Инбокс` в конце заметки | За компьютером, основной путь |
| Raycast | Глобальный хоткей `Ctrl+Space` на Quicklink к Advanced URI | Не отрываясь от работы |
| iPhone | Shortcut на том же URI, в шторке | На ходу |

URL для Quicklink и Shortcut, `#task` подставляется сам:

```
obsidian://advanced-uri?vault=SecondBrain&daily=true&heading=%D0%98%D0%BD%D0%B1%D0%BE%D0%BA%D1%81&mode=append&data=-%20%5B%20%5D%20{argument}%20%23task
```

`heading` — URL-кодированное «Инбокс», `data` — `- [ ] {argument} #task`.

Raycast перед записью переписывает фразу моделью haiku и при её осечке кладёт текст как есть. Поэтому неотредактированные фразы в инбоксе — штатная работа для разбора, а не аномалия.

**Встроенный Daily Notes не выключать**, хотя ежедневными заметками управляет Periodic Notes. Advanced URI читает формат и папку дневника строго из встроенного плагина (`internalPlugins.getEnabledPluginById("daily-notes").options`) и про Periodic Notes не знает: выключишь — захват сломается с «Daily notes plugin is not loaded». Настройки обоих совпадают — формат `YYYY/MM/YYYY-MM-DD`, папка `05. Дневник`, шаблон «Ежедневная заметка» — и расходиться им нельзя.

Захват снаружи идёт мимо модалки, поэтому ни `➕`, ни область строка не получает: область ставится на разборе, `➕` — агентом или при открытии строки в модалке.

## Клавиши

| Клавиши | Действие |
|---------|----------|
| `Cmd+D` | Сегодняшний дневник (команда Periodic Notes) |
| `Cmd+Shift+W` | Недельная заметка |
| `Cmd+Shift+T` | Создать или отредактировать задачу через модалку |
| `Cmd+Enter` | Закрыть задачу с датой выполнения |
| `Cmd+Shift+K` | Быстрый поиск по всем задачам |
| `Ctrl+Space` | Глобальный захват через Raycast |

## Откуда разметка: соответствие Things 3

Система переехала в Obsidian из Things 3 и Singularity 2026-09-09. Семантика GTD не менялась, менялся инструмент.

| Было в Things | Стало в Obsidian |
|---------------|------------------|
| Тег `P1` / `P2` / `P3` | `⏫` / `🔼` / без приоритета |
| Теги `deep` / `shallow` / `admin` | `#task/deep` / `#task/shallow` / `#task/admin` |
| Тег `<=15m` | `#task/15m` |
| Тег `waiting` | Статус `- [?]` |
| Тег `agenda:имя` | Wikilink на профиль в тексте задачи |
| Areas: Work, Family, Education, Content, Community | `#area/work`, `#area/family`, `#area/edu`, `#area/content`, `#area/community` |
| — | `#area/self` |
| Projects | Проектная заметка в `01. Проекты/` + wikilink в задаче |
| Someday | `#task/someday`, без дат |
| Deadline | `📅` — только объективно фиксированная дата |
| «Когда планирую сделать» | `⏳` — основная дата планирования |

Шестой области `#area/self` в Things не было: личное развитие, рефлексия, база знаний и рабочее окружение расползались по Family и соседним областям. При разборе бэклога эти задачи оказались самой крупной группой и получили свою роль.

# srekit-runbook

Создаёт runbook через `srekit runbook` и наполняет секции Symptoms, Diagnose, Mitigate, Verify.

## Требует

CLI `srekit` в `PATH`. Без него скилл не устанавливается.

## Когда срабатывает

«Нужен runbook на алерт X», «playbook», «зафиксируем, что делать при таком отказе».

## Что делает

Главный принцип — прескриптивно, а не нарративно. Не «мы посмотрели логи и увидели», а «посмотри логи командой такой-то». Императив настоящего времени, потому что читать это будет уставший дежурный в три ночи.

Обязательные параметры — `--service` и `--alert`: runbook привязан к конкретному алерту, иначе его не найдут в нужный момент.

## Границы

Не переносит в runbook timestamps и обстоятельства конкретного инцидента — это постмортем, а не инструкция. Не оставляет плейсхолдеры вроде `<your-cluster>` без объяснения, откуда взять значение.

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`sre`](../../../../docs/domains/sre/README.md).

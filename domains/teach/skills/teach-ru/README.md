# teach-ru

Учит новой теме на протяжении нескольких сессий. Состояние обучения живёт в рабочей директории: зачем учишься, по каким источникам, что уже усвоено. Следующая сессия продолжает с того места, где остановилась прошлая.

## Когда срабатывает

Только по явной команде `/teach-ru` с темой. Сам скилл не срабатывает (`disable-model-invocation: true`): обучение растягивается на недели, и начинать его случайно на фразе «объясни X» не нужно. Для Codex то же задаёт `agents/openai.yaml`.

Запускай в отдельной директории под тему: скилл считает текущую директорию воркспейсом и пишет в неё файлы.

## Что появляется в воркспейсе

| Файл | Зачем |
|------|-------|
| `MISSION.md` | Причина, по которой изучаешь тему. От неё зависит выбор каждого урока |
| `RESOURCES.md` | Источники с высоким доверием и сообщества, где навык проверяется вживую |
| `lessons/*.html` | Короткие уроки, по одной осязаемой победе на урок, с квизами и обратной связью |
| `reference/*.html` | Шпаргалки и справка, к которым возвращаешься чаще, чем к урокам |
| `learning-records/*.md` | Что усвоено и какое заблуждение исправлено. По ним выбирается следующий урок |
| `GLOSSARY.md` | Одно выбранное написание каждого термина вместо оригинала, транслитерации и кривого перевода |
| `assets/` | Общие стили и виджеты, из которых собираются уроки |
| `NOTES.md` | Предпочтения, как тебя учить |

Форматы файлов лежат рядом со `SKILL.md`: `MISSION-FORMAT.md`, `RESOURCES-FORMAT.md`, `LEARNING-RECORD-FORMAT.md`, `GLOSSARY-FORMAT.md`.

## Как устроено

Знание, навык и мудрость добываются по-разному. Знание берётся из источников, а не из памяти модели, поэтому первым делом наполняется `RESOURCES.md`. Навык ставится практикой с короткой петлёй обратной связи: вспоминание по памяти, интервалы, перемешивание связанных тем. За мудростью скилл отправляет к другим практикам, в сообщество.

Русская специфика: термины остаются английскими и получают пояснение при первом появлении, шрифты в HTML выбираются с нормальной кириллицей, сообщества ищутся сначала русскоязычные, а варианты ответов в квизах выравниваются по длине и падежу, чтобы правильный не выделялся.

## Границы

На разовый вопрос «объясни, как работает X» скилл избыточен. Практику в реальном мире он не заменяет, а знания модели не выдаёт за источник.

# agentops-canary

Канарейка контекста для длинных сессий: короткий маркер в начале каждого ответа, по которому видно деградацию раньше, чем она испортит работу.

## Проблема, которую решает

Контекст не кончается резко — он портится постепенно. Агент начинает игнорировать часть инструкций, забывает договорённости из начала сессии, теряет формат. Заметно это по плохому результату, то есть с задержкой: к моменту, когда ты понял, работа уже сделана неправильно.

## Когда срабатывает

«Поставь канарейку», «длинная сессия», «следи, чтобы ты не поплыл», «ты начал забывать инструкции».

Ставить стоит в начале долгой сессии — разбора инцидента, большого рефакторинга — а не тогда, когда деградация уже видна.

## Как работает

Каждый ответ начинается со строки вида `[🐤 Михаил · ход 14 · ✓✓?]`: обращение, счётчик хода, честная самопроверка по трём пунктам.

Работает это за счёт байт-стабильности. Пока хватка держится, строка воспроизводится точно. Когда внимание плывёт, ломается сначала она — формат, счётчик, обращение — и только потом содержательная часть ответа. Ранний сигнал стоит одной строки на ход.

## Trip-протокол

Сработала канарейка — не «соберись», а последовательность: записать чекпоинт в файл, пере-якориться по файлам (не по памяти), честно предложить рестарт с чекпоинта.

Чекпоинт пишется так, чтобы его прочитал агент, не видевший сессии: без отсылок к «как договорились выше», потому что никакого «выше» уже не будет.

## Границы

На коротких сессиях бесполезна: три хода не деградируют, а строка стоит токенов в каждом ответе.

Самопроверка обязана быть честной. `✓✓✓` из вежливости обесценивает весь механизм — тогда это просто украшение.

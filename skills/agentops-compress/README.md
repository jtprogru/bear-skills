# agentops-compress

Сжимает файлы, которые агент читает в начале каждой сессии: `CLAUDE.md`, `AGENTS.md`, правила, списки предпочтений.

## Зачем

Обычный текст стоит токенов один раз. Memory-файл — каждую сессию. Разросшийся `CLAUDE.md` на 3000 токенов при десяти сессиях в день превращается в заметную постоянную статью расходов, причём невидимую: она не появляется в диалоге, она уже потрачена к моменту, когда ты пишешь первое сообщение.

## Когда срабатывает

«Сожми CLAUDE.md», «мой AGENTS.md разросся», «правила занимают слишком много контекста», «ужми инструкции для агента».

## Как устроено

Механическая часть вынесена в [`scripts/memtool.py`](scripts/memtool.py) и не стоит токенов:

- `detect` — тип файла, оценка объёма, число якорей
- `backup` — копия в `$XDG_DATA_HOME`, намеренно вне дерева проекта
- `validate` — что потерялось при сжатии

**Якорь** — фрагмент, который обязан пережить сжатие дословно: путь, команда в бэктиках, имя переменной окружения, URL, значимое число. Сжатый текст может выглядеть целым и при этом перестать работать, если из него ушёл путь к правилу. Валидатор сравнивает множества якорей до и после и возвращает код 2, если что-то пропало.

При потере скилл делает точечный фикс — возвращает якорь на место и проверяет снова, до двух попыток. Переписывать заново нельзя: вторая генерация теряет другие якоря.

Бэкап уезжает в `$XDG_DATA_HOME/bear-skills/compress-backups/`, а не рядом с оригиналом. Копия правил в соседнем каталоге будет подхвачена автозагрузчиком, и сжатие увеличит контекст вместо того, чтобы уменьшить.

## Границы

Не трогает код, статьи и документацию для людей — там ценен ритм, а не плотность. Не перезаписывает файл без подтверждения. Не сжимает файлы короче ~400 токенов: риск выше выигрыша.

Про числа: скрипт даёт **оценку** по длине текста, а не замер токенайзером. В отчёте это называется оценкой, и скиллу запрещено выдавать её за измерение.

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`agentops`](../../../../docs/domains/agentops/README.md).

# obsidian-refactor-inbox

Обрабатывает входящие заметки: типизация, теги, aliases, связи, перемещение по PARA.

## Когда срабатывает

«Обработай входящие», «разбери 00. Входящие», «разложи заметки по папкам».

## Что делает

Определяет тип каждой заметки — атомарная мысль, ресурс, человек, проект, конспект — и дальше действует по типу: проставляет теги, добавляет связи с существующими заметками и MOC, переносит в нужную папку.

## Границы

Никогда не удаляет заметки. То, что потеряло актуальность, архивируется тегом `#archive`, а не исчезает.

Требует `BEAR_VAULT`. Подробная документация — [`docs/domains/obsidian/skills/obsidian-refactor-inbox.md`](../../../../docs/domains/obsidian/skills/obsidian-refactor-inbox.md).

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`obsidian`](../../../../docs/domains/obsidian/).

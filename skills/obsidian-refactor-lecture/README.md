# obsidian-refactor-lecture

Разбирает конспект лекции: выносит концепты, определения и теоремы в отдельные заметки, а сам конспект превращает в оглавление со ссылками.

## Когда срабатывает

«Обработай лекцию», «разбей конспект», «вынеси понятия из лекции», «лекция слишком большая».

## Что делает

Извлекает из конспекта то, что имеет смысл вне лекции: понятие, определение, теорему. Каждое становится атомарной заметкой, связанной с дисциплинарным MOC. Оригинал остаётся как структура курса.

За один запуск обрабатывает до трёх конспектов — ограничение намеренное, иначе качество извлечения падает.

## Границы

Не тащит в отдельные заметки то, что имеет смысл только внутри лекции: примеры «для иллюстрации», отсылки к предыдущему занятию.

Требует `BEAR_VAULT`. Подробная документация — [`docs/domains/obsidian/skills/obsidian-refactor-lecture.md`](../../../../docs/domains/obsidian/skills/obsidian-refactor-lecture.md).

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`obsidian`](../../../../docs/domains/obsidian/).

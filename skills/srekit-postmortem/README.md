# srekit-postmortem

Создаёт постмортем через `srekit postmortem` и наполняет секции фактами из текущего диалога.

## Требует

CLI `srekit` в `PATH`. Без него скилл не устанавливается.

```bash
brew install jtprogru/tap/srekit
# или
go install github.com/jtprogru/srekit@latest
```

## Когда срабатывает

«Написать постмортем», «разбор инцидента», «постмортем по INC-…» — в том числе без упоминания `srekit`.

## Что делает

Скаффолдит документ по шаблону и заполняет Summary, Impact, Timeline, Root cause, Action items, Lessons learned тем, что реально обсуждалось в сессии. Метаданные — title, severity, owner, время начала и конца — берёт из контекста или спрашивает.

Там, где данных нет, ставит GAP-маркер вместо правдоподобного текста. Пустое место видно при вычитке, выдуманная деталь — нет.

## Границы

Blameless: без личных имён, без «человеческой ошибки» в качестве root cause. Не выдумывает timestamps и метрики.

Промпт для модели — [`SKILL.md`](SKILL.md). Домен — [`sre`](../../../../docs/domains/sre/README.md).
